Local File Processing

Uploaded files are selected into your browser only. The converter reads, converts, and prepares downloads on your device using browser APIs, JSZip, and FFmpeg.wasm for supported media conversions.

This frontend does not include a file upload endpoint and does not intentionally send selected file contents to the site operator or another server.

Third-Party Runtime Files

Media conversion may load FFmpeg.wasm runtime files from a public CDN. The selected media file remains in browser memory and is not uploaded by the converter during this process.

Storage and Retention

Selected and converted files remain in browser memory until you download, clear, refresh, or close the page. This version does not store uploaded files or converted outputs in server storage.

Purpose of Processing

  • Convert supported files locally in the browser.
  • Create downloadable converted files without server-side storage.

User Rights

Depending on your location, you may have rights to access, correct, export, restrict, object to, or delete personal data. Send privacy requests to contact.marfeyx@gmail.com.
